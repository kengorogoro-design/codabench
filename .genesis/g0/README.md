# MIGI G0 — Reality Ecology Substrate

Status: NON-CANON RESEARCH. MIGI_CREDIT=0. ADMISSION=DENY.

Current slice: custody/selection correction. It provides no new intelligence
mechanism. The bootstrap seeds emit investigation suggestions; they do not
produce the Codabench patches. The self-rewriting generator uses builder-written
templates and a supplied poor_transfer flag. It is a byte-generation demonstration,
not reality-selected cognition or an autonomously discovered successor rule.

Selection requires all winner gates on all matched courts and componentwise
outcome/cost dominance. Missing courts, duplicates, mixed identities, NaN/invalid
costs and truthy nonboolean attestations fail closed. ExternalEvidence is a
trusted-importer preflight data type, not cryptographic external attestation.

Effect authority is denied when omitted, unavailable or nonboolean. Known-source
execution checks the frozen identity, stages a copy, bounds process resources and
output, and terminates the process group. Same-UID ambient access, hostile process
escape, OS/network isolation and independent resource attestation remain UNPROVEN.
Do not run arbitrary hostile bundles on this runner.

Actual producer output is hashed before edits. A probe-only output cannot inherit
a builder-created patch; any edit breaks delivery attribution. Same-host custody
alone does not authenticate independent external outcomes or admit MIGI.

Run `python -m pip install -r requirements-test.txt`, then `python replay_gate.py`.
The ledger requires POSIX advisory locking and durable local rename/fsync support;
Windows and remote-filesystem durability are not qualified by this slice.

G0 is intentionally **not a cognitive architecture**. It does not require a parser,
planner, memory, world model, representation family, agent loop, search method,
learning rule, neural network, symbolic engine, or a fixed mutation grammar.

The only privileged layer is operational substrate that any implemented intelligence
must physically use somehow: executable bytes, bounded I/O, immutable evidence,
isolated execution, candidate/successor custody, external outcome records, rollback,
and explicit authority boundaries.

A candidate is an opaque bundle. Its internals are not inspected by G0 for admission.
A generator is also an opaque candidate bundle; therefore a successor can replace the
mechanism that generated successors. The substrate compares only externally evidenced
outcomes and operational invariants, never an internal 'intelligence score'.

G0 is not MIGI. It is the first clean break from the R-series' builder-authored
cognitive ontology. R4–R7 are retained only as fossil evidence / bootstrap species.

## Effect relay (operational substrate only)

Opaque bundles may now request runtime-registered external capabilities through a thin
receipt relay. The substrate does not assign semantic meaning to capability names and
does not require a planner, tool policy, memory model, or agent loop. It only enforces
a bounded number of effects, external authority checks, request/result hashing, and a
tamper-evident receipt ledger. This is required plumbing for real-world self-hosting;
it is not intelligence evidence.
